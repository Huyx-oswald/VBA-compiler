FinanceRPA 加载宏安装说明
==========================

安装步骤
--------
1. 确认已安装 WPS 表格（2019 及以上版本）
2. 关闭所有 WPS 窗口
3. 双击 install.vbs
4. 点击 Yes 开始安装
5. 安装完成后打开 WPS 表格

验证安装
--------
1. 打开 WPS 表格
2. 查看功能区是否有「加载项」选项卡
3. 点击「加载项」应看到「财务RPA」工具组
4. 点击任意按钮测试功能

伴生文件（首次运行清洗时）
--------------------------
库存/库龄类清洗会用到「物料组模板」「期初库存价值表」「历史期库龄表」等伴生文件。
首次点击按钮时若弹出「请选择伴生文件」对话框，请定位到这些 xlsx 文件；
选定后会被记住，下次自动使用；文件移动/删除后会再次弹框。

如果看不到按钮
--------------
1. 右键功能区 → 自定义功能区
2. 勾选「加载项」选项卡
3. 确定后重新打开 WPS

卸载方法
--------
1. 关闭 WPS
2. 删除启动文件夹中的 FinanceRPA.xlam
   （路径通常为：C:\Users\用户名\AppData\Roaming\Kingsoft\office6\startup\）
3. 重新打开 WPS，选项卡消失

系统要求
--------
- WPS 表格 2019 及以上
- Windows 10/11
- 无需安装 Node.js 或其他依赖
